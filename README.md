# Мессенджер

## Запуск
```
npm install
npm start
```

## Функции
- Телефон + пароль (bcrypt + JWT), @username, поиск людей
- Личные и групповые чаты, real-time (Socket.IO, автопереподключение)
- Статусы «в сети» / «был(а) недавно»
- Уведомления браузера о новых сообщениях
- Добавление участников в группу после создания
- 🔒 Секретные чаты: сквозное шифрование (ECDH P-256 + AES-GCM), сервер хранит только шифротекст
- Фото/видео без потери качества, голосовые, аватарки
- Редактирование/удаление сообщений, настройки конфиденциальности
- PWA — устанавливается как приложение
