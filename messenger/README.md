# Мессенджер

## Запуск
```
npm install
npm start
```
Откройте http://localhost:3000 (для звонков/микрофона лучше https или localhost).

## Функции
- Регистрация/вход по номеру телефона + пароль (bcrypt + JWT)
- Личные и групповые чаты (real-time через Socket.IO)
- Фото и видео в оригинальном качестве (без пережатия)
- Аватарки (нажмите на круглый аватар сверху слева)
- Голосовые сообщения (кнопка 🎤 — нажмите для записи, ещё раз — отправить)
- Редактирование (✏️) и удаление (🗑) своих сообщений — появляются при наведении
- Индикатор «печатает…»
- Данные в db.json, файлы в uploads/
